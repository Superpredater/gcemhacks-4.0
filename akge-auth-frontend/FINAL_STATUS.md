## 📞 Support & Maintenance

### Common Issues
- **White Screen**: Check browser console for errors
- **Styling Issues**: Clear browser cache and rebuild
- **Performance**: Check network tab for slow requests
- **Responsive Issues**: Test on actual devices

### Troubleshooting
1. Clear browser cache: Ctrl+Shift+Delete
2. Restart dev server: Stop and run `npm run dev` again
3. Check console: F12 → Console tab
4. Verify dependencies: `npm install`
5. Check Node version: `node --version` (should be 16+)
