## 📞 Support

### Common Issues
1. **White Screen**: Check browser console (F12)
2. **Styling Issues**: Clear cache (Ctrl+Shift+Delete)
3. **Performance**: Check network tab
4. **Responsive Issues**: Test on actual devices

### Troubleshooting
1. Clear browser cache
2. Restart dev server
3. Check console for errors
4. Verify dependencies: `npm install`
5. Check Node version: `node --version` (should be 16+)
